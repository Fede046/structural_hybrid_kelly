* **Criterio 1: Il motore accetta frazioni scalari, per traiettoria e per passo (M, T), e restituisce (M, T+1) float64 con colonna 0 nulla.**
  * *Esito:* **Soddisfatto** `[V]`.
  * *Dettaglio:* `simulate_growth` accetta frazioni scalari float, array 1D per passo `(T,)`, array 2D per passo `(1, T)`, array 2D per traiettoria `(M, 1)` e matrici complete `(M, T)`. In tutti i casi restituisce un `np.ndarray` con shape `(M, T + 1)`, `dtype=np.float64` e colonna iniziale identicamente pari a 0.0. Verificato tramite `test_simulate_growth_broadcast_shapes` `[V]`.

* **Criterio 2: Caso calcolato a mano, M = 1, T = 3, esiti [vinta, persa, vinta], frazioni [0.1, 0.2, 0.3], b = 1: le traiettorie valgono 0, ln 1.1, ln 1.1 + ln 0.8, ln 1.1 + ln 0.8 + ln 1.3, entro 1e-12.**

  * *Dettaglio:* Il test `test_simulate_growth_hand_calculated_case` verifica i 4 punti della traiettoria rispetto ai valori analitici attesi con tolleranza `rtol=1e-12`. L'asserzione passa con discrepanza massima $< 10^{-16}$ `[V]`.

* **Criterio 3: Una frazione scalare e una matrice (M, T) con lo stesso valore costante danno lo stesso risultato (rtol 1e-12).**
  * *Esito:* **Soddisfatto** `[V]`.
  * *Dettaglio:* Il test `test_simulate_growth_scalar_matrix_equivalence` confronta l'output ottenuto con scalare `f=0.18` e matrice costante `(M, T)` di valore `0.18`. L'uguaglianza è verificata con `rtol=1e-12` `[V]`.
